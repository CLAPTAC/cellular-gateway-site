# Cellular Gateway site

Public marketing + docs site for [CLAPTAC/cellular-gateway](https://github.com/CLAPTAC/cellular-gateway).

Published at https://claptac.github.io/cellular-gateway-site/

## Source

This repository holds the **generated** site. The source (page content, templates and
`build.py`) lives in [`site-src/`](https://github.com/CLAPTAC/cellular-gateway/tree/main/site-src)
in the main repository. To update the site, edit the content there, run
`python3 site-src/build.py --out <path to this repo>`, then commit the result here.
