Documentation

Cellular Gateway is an open-source, self-hosted platform that turns Android phones into managed SMS and voice gateways for your applications.

Architecture

External App  --REST-->  Gateway Server  --WebSocket-->  Android Device

Components

  • Server — FastAPI, PostgreSQL/SQLite, device sessions, commands
  • Android app — Kotlin gateway with QR setup, SMS, and calls
  • Dashboard — Next.js management portal

Current capabilities

Phase Capability
1 Core device link, auth, heartbeats, commands, portal
2 Real SMS send/receive + message history
3 Voice call start/end + call state history
4 Device groups, routing, queue, failover
