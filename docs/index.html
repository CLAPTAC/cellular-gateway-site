Overview

Cellular Gateway is an open-source, self-hosted platform that turns Android phones into managed SMS and voice gateways for your applications.

What it does#

You run a gateway server and connect one or more Android phones to it. Your applications call the server's REST API to send SMS or place calls, and the server forwards each request to a phone over a persistent WebSocket. The phone uses its own SIM, then reports the result. Inbound SMS and status changes can be delivered to your systems as signed webhooks.

Request path
Your application  --REST-->  Gateway server  --WebSocket-->  Android phone  -->  SIM / carrier
                    ^                |
                    '----webhooks----'

What happens when you send an SMS#

  1. Request. Your service calls POST /api/v1/messages with an API key. The gateway validates the request and chooses a device by device key, group strategy, or health score.
  2. Command. The gateway stores the message and an SMS_SEND command. If the chosen phone is offline and queueing is allowed, the command waits as QUEUED.
  3. Delivery to the phone. The command is pushed over the phone's WebSocket. The phone acknowledges it (ACKNOWLEDGED) and hands the text to Android's SMS service.
  4. Result. The phone reports COMPLETED or FAILED. The message status updates, and SMS_SENT or SMS_FAILED webhooks fire. A failed SMS sent through a group is retried on another phone.
Before you rely on it

SMS and call behaviour has been verified with the simulator and automated tests but not yet on physical phones with SIM cards. Test with real hardware before using it for anything important. See Operations and limits.
