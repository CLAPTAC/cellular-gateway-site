Multi-device routing

Phase 4 pools multiple Android gateways behind groups and routing strategies.

Strategies

  • healthiest
  • round_robin
  • highest_battery
  • least_load

Send via group

POST /api/v1/messages
{
  "group": "dialog-pool",
  "to": "+9477xxxxxxx",
  "message": "Routed SMS",
  "queue": true,
  "failover": true
}

queue=true waits for an online member. failover=true retries another device after SMS failure.
