Multi-device routing

Pool phones into groups, choose a device by health, battery or load, queue while offline, and fail SMS over to another phone.

Overview#

  • Device groups hold the phones you want to use together, for example one per carrier.
  • Four routing strategies pick a phone for each message or call.
  • If you omit both device and group, the gateway chooses among all enabled devices.
  • queue: true keeps a message or call until a suitable phone is online. Sending to a group queues automatically.
  • A failed SMS sent through a group is retried on another member (failover).

Create a group#

Use the dashboard's Groups page, or the API (administrator):

bash
curl -X POST https://gateway.example.com/api/v1/groups \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{
    "name": "Dialog pool",
    "slug": "dialog-pool",
    "routing_strategy": "healthiest",
    "device_ids": ["DEVICE_UUID_1", "DEVICE_UUID_2"]
  }'

Send through a group#

bash
curl -X POST https://gateway.example.com/api/v1/messages \
  -H "X-API-Key: $API_KEY" -H "Content-Type: application/json" \
  -d '{
    "group": "dialog-pool",
    "to": "+15551234567",
    "message": "Routed SMS",
    "queue": true,
    "failover": true
  }'

Strategies#

Online phones are always preferred over offline ones. Within that set:

StrategyChooses
healthiest (default)The highest health score (see below)
round_robinThe phone with the fewest in-flight commands, then by score. It balances by current load, not a strict rotation
highest_batteryThe phone with the most battery
least_loadThe fewest in-flight commands plus active calls

Health score#

Each enabled phone gets a score. Higher is better.

ComponentEffect
Online (live WebSocket)+1000
Battery above the device's minimum+2 per percentage point (minimum defaults to 15%)
In-flight commands (queued, sent, acknowledged)up to +200, minus 20 per command
Active callsup to +100, minus 50 per call
Priority (1 to 1000, default 100)+(200 minus priority), never below 0. Lower numbers rank higher
Battery below the minimum-500

Signal strength is not part of the score. Preview a decision without sending anything with GET /api/v1/groups/{id}/preview or GET /api/v1/groups/route-preview.

Queueing#

With queue: true (or any group send), a command for an offline phone is stored as QUEUED. A background worker checks every 5 seconds and dispatches it when the phone connects. With queue: true on a group send it can also reassign the command to another online member instead of waiting.

Failover#

  • Applies to SMS only, and only when the message was sent to a group.
  • After a FAILED result the gateway retries on another group member, excluding the phone that failed.
  • There are at most 3 attempts in total. Set failover: false to disable it.
  • Calls are never retried automatically.
