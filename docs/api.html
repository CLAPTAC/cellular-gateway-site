API

Base path: /api/v1. Interactive docs are available at /docs on your running server.

Authentication

  • Admin JWT: POST /api/v1/auth/login then Authorization: Bearer …
  • Application key: create in dashboard, send X-API-Key: cgk_…

Send SMS

curl -X POST http://HOST:8000/api/v1/messages \
  -H "X-API-Key: cgk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "device": "dev_YOUR_DEVICE_KEY",
    "to": "+9477xxxxxxx",
    "message": "Hello from Cellular Gateway"
  }'

Start a call

curl -X POST http://HOST:8000/api/v1/calls \
  -H "X-API-Key: cgk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"device":"dev_YOUR_DEVICE_KEY","to":"+9477xxxxxxx"}'

Route via a device group

curl -X POST http://HOST:8000/api/v1/messages \
  -H "X-API-Key: cgk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "group": "dialog-pool",
    "to": "+9477xxxxxxx",
    "message": "Routed SMS",
    "queue": true,
    "failover": true
  }'
