Devices

Android app

Build and install the gateway app, connect it to your server, and keep it reliable on real phones.

Build and install#

Open the android/ project in Android Studio (JDK 17), or build from the command line:

bash
cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk

The app targets Android 8.0 (API 26) and newer, and is currently version 0.3.0. The release build type has no signing configuration, so assembleRelease produces an unsigned APK until you add your own signing setup.

Connect#

  1. Create a device in the dashboard. The one-time credentials appear as a QR code.
  2. Open the app and either scan the QR code or enter the server URL, device key and device token.
  3. Allow permissions for SMS and phone when prompted.
  4. Tap Connect. The device should show ONLINE in the dashboard.

The app runs a foreground service. It registers over REST, opens the WebSocket, sends a heartbeat every 10 seconds, reconnects after 3 seconds on failure, and starts again after a device reboot.

Keeping phones reliable#

  • Sideload the APK. Google Play restricts the SMS and call permissions to default SMS and dialer apps.
  • Disable battery optimization for the app, and allow autostart and background activity on manufacturers that restrict it.
  • Use a SIM plan that suits your expected volume. Android may throttle or prompt on bursts of outgoing SMS.
  • Keep the phone charged and on a stable connection. The gateway marks a phone offline when no heartbeat arrives for 45 seconds and the socket is gone.
  • Use the min_battery_percent device setting to steer routing away from low-battery phones.
