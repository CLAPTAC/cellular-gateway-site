Android app

Open the android/ project in Android Studio, build a debug APK, and install it on a real phone.

Connect

  1. Create a device in the dashboard (or rotate token for an existing one).
  2. Set the phone server URL to your PC LAN IP, e.g. http://192.168.x.x:8000.
  3. Prefer QR scan over typing credentials.
  4. Allow SMS and phone permissions when prompted.
  5. Tap Connect and confirm the device shows ONLINE.

CLI build

cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk

Notes

  • 10.0.2.2 is only for the Android emulator talking to the host machine.
  • Keep the app connected (foreground service) while sending SMS or calls.
  • Some OEMs need autostart / background allowances for reliability.
