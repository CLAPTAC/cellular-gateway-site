SMS

Phase 2 enables real SMS send/receive through the connected Android SIM.

Requirements

  • Android app with SEND_SMS / RECEIVE_SMS granted
  • Device status ONLINE
  • Valid API key

Send

POST /api/v1/messages
{
  "device": "dev_...",
  "to": "+9477xxxxxxx",
  "message": "Hello"
}

Statuses move through queued/sending into SENT or FAILED. Inbound SMS appears as INBOUND / RECEIVED in message history.

Carrier charges and local messaging regulations still apply.
