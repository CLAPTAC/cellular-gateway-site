Configuration

Every server environment variable with its default, plus the Compose and dashboard settings used in production.

Server settings#

Set these as environment variables, or in server/.env for local development. The production compose files pass the ones listed below into the container.

VariableDefaultDescription
ENVIRONMENTdevelopmentproduction enables startup safety checks, secure cookies and HTTPS-only webhook URLs, and disables /docs
SECRET_KEYplaceholderJWT signing key. Must be a random string of at least 32 characters in production
DATABASE_URLsqlite+aiosqlite:///./cellular_gateway.dbSQLAlchemy async URL, for example postgresql+asyncpg://user:pass@host:5432/db
ADMIN_EMAIL, ADMIN_PASSWORDadmin@example.com, changemeBootstrap administrator created on first start
CORS_ORIGINShttp://localhost:3000,http://localhost:8000Allowed browser origins, comma-separated. Also the allowed Origin values for cookie-authenticated writes
ACCESS_TOKEN_EXPIRE_MINUTES1440 (480 in production compose)Lifetime of login tokens and the session cookie
DEVICE_HEARTBEAT_TIMEOUT_SECONDS45A device with no live socket and an older heartbeat is marked OFFLINE
AUTO_CREATE_SCHEMAtrueCreate tables on startup. Production compose sets false and uses Alembic
LOG_LEVELINFOPython log level
LOGIN_RATE_LIMIT_ATTEMPTS10Failed logins allowed per IP and per email in the window. Device registration and device WebSocket authentication allow three times this value per IP
LOGIN_RATE_LIMIT_WINDOW_SECONDS300Rate-limit window
WEBHOOK_ALLOW_PRIVATE_TARGETSfalseAllow webhooks to private or loopback addresses. Leave off unless the receiver is trusted and internal
FORWARDED_ALLOW_IPSloopback and private rangesProxies allowed to set X-Forwarded-For (comma-separated IPs or CIDRs)

Compose variables (production)#

VariableUsed byDescription
GATEWAY_DOMAINboth filesPublic hostname. Sets CORS and the dashboard's API URL, and is the Caddy site address
POSTGRES_PASSWORDboth filesDatabase password
GATEWAY_API_PORTshared-hostLoopback port for the API (default 18000)
GATEWAY_DASHBOARD_PORTshared-hostLoopback port for the dashboard (default 13000)

.env.production.example lists all of them, including the optional server settings above.

Dashboard#

NEXT_PUBLIC_API_URL is read at build time and must be the public URL of the API (for example https://gateway.example.com). The production compose files pass it as a build argument, so rebuild the dashboard image if the domain changes.

Defaults that production rejects#

  • SECRET_KEY that starts with change-me or is shorter than 32 characters
  • ADMIN_PASSWORD of changeme, admin or password, or shorter than 12 characters
  • ADMIN_EMAIL of admin@example.com
  • A SQLite DATABASE_URL
  • CORS_ORIGINS containing localhost or 127.0.0.1
