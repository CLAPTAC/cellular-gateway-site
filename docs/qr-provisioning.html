QR provisioning

Avoid typing long device tokens. The dashboard encodes connection details into a QR code.

Payload

{
  "v": 1,
  "server_url": "http://10.16.56.90:8000",
  "device_key": "dev_...",
  "device_token": "dvt_..."
}

Flow

  1. Create a device (or use Show QR again to rotate the token).
  2. Set Server URL for the phone to a LAN-reachable address.
  3. On the phone, tap Scan QR.
  4. The app fills credentials and connects.
