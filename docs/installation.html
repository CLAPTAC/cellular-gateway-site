Installation

Run the gateway locally with SQLite, or use Docker Compose with PostgreSQL when available.

Local server

cp .env.example .env
cd server
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

Important: bind to 0.0.0.0 so real phones on your LAN can reach the API. Use your PC LAN IP in the Android app / QR provisioning URL (not localhost).

Dashboard

cd dashboard
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev

Default admin

Emailadmin@example.com
Passwordchangeme

Change these in .env before any real deployment.

Health check

curl http://localhost:8000/health

Docker Compose

A docker-compose.yml is included for PostgreSQL + server + dashboard. Requires Docker Compose support on the host. 

cp .env.example .env
docker compose up --build
